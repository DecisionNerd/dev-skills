# Track Work

Make intent and progress visible on GitHub so agents and humans share ownership.

**Prerequisite:** [Orientation](../orientation/index.md). Related: [This is Fine](../concepts/01-this-is-fine-stance.md), [Smallest Next Step](../concepts/03-smallest-next-step.md), [Vision-Tied Goals](../concepts/08-vision-tied-goals.md).

## What it is

Make intent and progress visible on GitHub so agents and humans share ownership. A strategy is a claim about what kind of progress this moment owes the project — then a recognisable set of [practices](../practices/index.md) that tend to earn it.

## Why it works

Without a named strategy, teams mix shipping, rewriting, and tidying in one thrashy session. Naming the strategy constrains tool choice and makes stop conditions obvious.

## When to use it

When work is invisible, duplicated, or unscoped. Not a substitute for fixing prod.

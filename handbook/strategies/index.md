# Strategies

A strategy is a building goal with reasoning behind it — not a bag of skill names. Read **What it is** and **Why it works** even if you already know the practices; the reasoning tells you when to break the pattern.

Most sessions need **one** strategy. Running all seven at once is usually a sign you skipped [Orientation](../orientation/index.md) — or skipped your [lifecycle](../flow/index.md) / [project shape](../paths/index.md).

**Prerequisite:** [Orientation](../orientation/index.md). Vocabulary: [Concepts](../concepts/index.md). **Lifecycle:** [How work flows](../flow/index.md). **Architecture / shape:** [Architecture](../architecture/index.md) · [Paths](../paths/index.md).

| Path | Draw these strategies first |
| --- | --- |
| [Simple website](../paths/01-simple-website.md) | Orient → Craft and Harden → Ship (light) → Tidy |
| [CLI](../paths/02-cli.md) | Orient → Track Work → Diagnose and Fix → Craft and Harden → Ship |
| [Python package](../paths/03-python-package.md) | Orient → Track Work → Craft and Harden → Ship |
| [Monorepo](../paths/04-monorepo.md) | Full set; emphasize Track Work, Ship, Agent Hygiene, Diagnose and Fix |
| [Compute](../paths/compute/index.md) | Ship + Craft; KISS before a second platform; secrets via ESC |

- [Orient](01-orient.md) — Recover vision and situation; pick an achievable goal.
- [Track Work](02-track-work.md) — Make progress legible on issues, milestones, and PRs.
- [Diagnose and Fix](03-diagnose-and-fix.md) — Put out real fires with evidence-backed repair.
- [Craft and Harden](04-craft-and-harden.md) — Research, refactor, test, observe, document — without boiling the ocean.
- [Ship](05-ship.md) — Readiness → merge → stage → production with sober gates.
- [Agent Hygiene](06-agent-hygiene.md) — Design, analyze, optimize agents; slap and drain when stupid.
- [Tidy and Recover](07-tidy-and-recover.md) — Clear dangling workspaces, artifacts, caches; reclaim the room.

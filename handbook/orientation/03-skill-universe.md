# Skill Universe

The set of skills available **in this session**: DecisionNerd pack, DocSlime, ProductFeeling, Impeccable, and anything vendored under the repo.

## What it is

Recommendations that only know one pack are half-blind. A UI feel problem wants ProductFeeling → Impeccable; a missing product story wants DocSlime; a runaway agent wants `agents slap`; a lost human wants `idk-now`.

## Why it works

The smallest matching skill beats a generic “write code.” Discover vendored skills under `.agents/skills/`, `.cursor/skills/`, `skills/`, and paths named in `AGENTS.md`.

## Do

- Inventory before recommending
- Prefer vendored copies when both global and local exist
- Suggest install only when the user wants new capability

## Don't

- Install skills silently
- Recommend a swarm

`research-it`

Research a technical or product question before building — APIs, libraries, prior art in-repo, external docs, tradeoffs, and a recommendation. Use when the user says "research it", asks what to use, compares options, wants an RFC-style brief, or needs evidence before implementation. Read-only by default; ask before installing dependencies or writing production code. Hand off to fix-it / recon issue / issues create when ready to plan or track.

## Install

```bash
npx skills add DecisionNerd/dev-skills --skill research-it
```

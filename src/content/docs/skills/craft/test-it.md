`test-it`

Add, fix, or harden tests for the current change, issue, or failing suite. Use when the user says "test it", asks for coverage, regression tests, BDD evidence mapping, flaky-test stabilization, or CI test gaps. Prefer existing runners and patterns; ask before large new frameworks. Pair with fix-it / diagnose-bug / check-readiness when tests prove a repair or readiness gate.

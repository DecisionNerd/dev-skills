`milestones`

Work GitHub milestones with command arguments: create, update, critique, narrow, widen, merge, clean, refine, explain, document, close, status, and plan. Default with only a milestone identifier (and optional details) is execute completion work — critical-path issue plan/implement, ready-check, merge, stage/ship where repo policy has them — not milestone-admin. Explicit commands still do admin. Use when the user asks about milestones, `/milestones <command|title|number>`, release/version planning, or finishing a milestone slice.

## Install

```bash
npx skills add DecisionNerd/dev-skills --skill milestones
```

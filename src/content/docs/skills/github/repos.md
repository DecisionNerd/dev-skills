`repos`

Manage GitHub repositories: create/settings, split, combine, monorepo moves, architecture review, CI harden/simplify, and secrets (Pulumi ESC by default). Use when the user says repos, `/repos <command>`, wants to carve or join repos, redesign monorepo layout, harden workflows, or set up secrets without long-lived GitHub Actions secrets. Mutating GitHub/Pulumi/cloud requires explicit approval.

## Install

```bash
npx skills add DecisionNerd/dev-skills --skill repos
```
